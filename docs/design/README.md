# Design records

These are the design records for ONEXUS, written while I built it with coding agents. Each spec in `specs/` is one decision and the reasons behind it: the options considered, what was chosen, and what it would cost. Each plan in `plans/` is the order the work was done in.

They are kept as they were written, so some describe ideas that changed or were cut later. The README and the code are the current truth; these show how it got there.

5 specs, 15 plans.
